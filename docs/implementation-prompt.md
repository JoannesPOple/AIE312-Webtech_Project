# Implementation Prompt

Build a simple team AI Portfolio web application in this repository. Use React, TypeScript, and Vite for the frontend; Node.js, Express, and the official `@google/genai` SDK for the backend. Use the Gemini API with `GEMINI_API_KEY` and `GEMINI_MODEL`. Keep all team data in `BE/src/data/portfolio.json`. Implement a responsive Portfolio UI, a simple Chat UI, `GET /api/health`, `GET /api/portfolio`, and `POST /api/chat`. Keep the Gemini API key on the backend only and return a clear demo response when the key is not configured. Add `.env.example`, README instructions, a Render deployment configuration, and a GitHub Actions workflow that runs install, lint, and build. Keep the implementation beginner-friendly and verify it with production builds and API smoke tests.
